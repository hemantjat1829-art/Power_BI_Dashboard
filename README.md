 📌 Project Overview

This project presents an interactive Sales Data Analysis Dashboard built using Microsoft Power BI to analyze sales performance, revenue distribution, profitability, product categories, and sales channels across multiple countries.

The dashboard provides a consolidated view of key business metrics and enables users to explore sales trends using dynamic filters for year, quarter, month, and country.

 🎯 Project Objectives

- Analyze overall sales revenue and gross profit.
- Monitor gross margin and total order quantities.
- Compare monthly revenue and sales channel performance.
- Identify the top-performing and lowest-performing countries by revenue.
- Evaluate revenue contribution across product categories.
- Understand geographical sales distribution.
- Enable interactive analysis through dynamic slicers and visualizations.

 🛠️ Tools & Technologies

- Microsoft Power BI — Dashboard development and reporting
- Power Query — Data transformation and cleaning
- DAX — Measures and KPI calculations
- Data Visualization — Interactive charts, cards, and maps

 📈 Key Performance Indicators (KPIs)

The dashboard displays five primary business metrics:

| KPI | Value Displayed |
|---|---:|
| Total Orders | 3K |
| Gross Margin | 45.94% |
| Total Orders Quantity | 7K |
| Total Revenue | 645.22K |
| Total Gross Profit | 296.38K |

These values reflect the dashboard screenshot and may change when filters are applied.

 📊 Dashboard Features

 1. Monthly Revenue and Profit Analysis
- Compares monthly revenue and sales channel count metrics.
- Highlights variations in performance across months.
- Helps identify periods with stronger or weaker sales performance.

 2. Top 5 Countries by Revenue
Ranks the five highest-revenue countries displayed in the dashboard:
- United Kingdom
- Germany
- France
- Italy
- Spain

 3. Bottom 5 Countries by Revenue
Highlights the five lowest-revenue countries shown:
- Belgium
- Switzerland
- Finland
- Czechia
- Ireland

This comparison helps identify markets that may require further investigation.

 4. Sales Channel Revenue Comparison
Compares revenue contribution across four sales channels:
- Online Store
- Corporate
- Retail Partners
- Marketplace

The pie chart displays both revenue values and percentage contributions, making it easier to compare channel performance.

 5. Product Category Revenue Analysis
Analyzes revenue distribution across five product categories:
- Hiking
- Camping
- Travel
- Cycling
- Fitness

The doughnut chart presents the percentage contribution of each category to the displayed category revenue total.

 6. Geographical Sales Distribution
Uses a map visualization to display country-level sales distribution across European markets.

 7. Interactive Filters
Users can filter the dashboard by:
- Year
- Quarter
- Month
- Country

These slicers allow users to investigate performance across different periods and geographical markets.

 💡 Business Insights

The dashboard supports business questions such as:

- Which countries generate the highest revenue?
- Which markets contribute the least revenue?
- Which sales channels contribute most to total sales?
- Which product categories account for the largest revenue share?
- How do revenue and profitability vary across reporting periods?
- How does country selection affect overall business performance?

 🚀 How to Use the Dashboard

1. Download or clone this repository.
2. Open the `.pbix` file using Microsoft Power BI Desktop.
3. Refresh the dataset if required.
4. Use the year, quarter, month, and country slicers to filter the report.
5. Explore the KPI cards, charts, and map to analyze sales performance.
